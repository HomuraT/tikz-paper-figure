% rdf-triples: RDF data about one resource in the W3C convention (RDF 1.1 XML Syntax, Fig. 1; the RDF
% Primer's diagrams): IRIs in ovals, literals in rectangles, a blank node as a small empty circle, each
% predicate a labelled arrow from subject to object. The resource the figure is about has the thicker oval
% (`rdf focus`); the blank node _:b1 shows the n-ary pattern, an award with its year and its co-winner.
% Key and prefixes below the graph; the prefixes box is the wheat box of Matplotlib's "Placing text boxes".
% Predicate labels sit on a white patch in the middle of their arrow; the one short horizontal arrow
% (dbo:spouse) takes its label above instead, or the patch would hide the arrowhead.
% Build:  python <skill>/scripts/build_figure.py rdf-triples.tex
