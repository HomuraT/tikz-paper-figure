# Examples

Two walk-throughs with their inputs, commands, outputs and the checks that were run. Both were produced on Windows 11 with TeX Live 2025 from the repository root; the commands and their output are copied from the shell.

- [`results-from-csv`](results-from-csv): a results grid generated from a CSV, four benchmarks, one of them sorted ascending because lower is better.
- [`constrained-revision`](constrained-revision): a reference line added to an existing chart under a change list and a keep list, with the diff and the before/after sheet.

The 63 example figures themselves live inside the skill, in `skills/tikz-paper-figure/assets/examples/`, and are listed with the question each answers in the [gallery](../skills/tikz-paper-figure/references/gallery.md).

The [ontology guide](../skills/tikz-paper-figure/references/ontology.md) covers nine ontology/RDF figures, including six soft-style examples. The 26–28-node variants demonstrate dense graphs; their layouts are examples, not requirements.
